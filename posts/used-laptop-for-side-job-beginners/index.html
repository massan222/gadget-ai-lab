副業用のパソコン、中古で始めるという選択

在宅で副業を始めようと思っても、作業用のパソコンが手元にない方は多いと思います。新品のノートパソコンは数万円台後半からの価格が多く、続くか分からない段階では出費が気になります。そこで候補になるのが、法人などで使われた後に整備された中古ノートパソコンです。この記事では予算3〜5万円を目安に、中古ノートパソコン2台と、あると便利な周辺機器1つを紹介します。

私は自宅の Windows 11 のデスクトップ PC で Claude Code を使い、Excel マクロの編集やメール返信の下書きを自動化しています。ただ、中古ノートパソコンは使っていません。そのため、今回の商品は仕様とショップのレビューをもとに整理しています。文章作成、事務作業、オンライン打ち合わせといった、副業でよくある作業を想定して選びました。

選び方の要点

CPU は第8世代以降の Core i5 を目安に

CPU（パソコンの頭脳にあたる部品）は、Intel 製なら「Core i5」以上が事務作業に使いやすい目安です。Windows 11 は、Intel 製 CPU ならおおむね第8世代以降が動作要件になっています。古い世代はアップデートやサポートの面で不安が残るため、「Win11正式対応」の表記を確認しましょう。

メモリは8GB以上、余裕があれば16GB

メモリ（作業机の広さにあたる部品）が多いほど、複数のアプリを同時に開いても動作が重くなりにくくなります。文章作成や表計算が中心なら、8GBで足りる場合が多いです。ビデオ会議をしながらブラウザのタブを多く開くような使い方なら、16GBあると余裕が出ます。

保存装置は SSD、Webカメラと Office も確認

SSD（読み書きが速い保存装置）なら、起動やアプリの立ち上がりが速くなります。オンライン面談がある副業なら、Webカメラ付きが便利です。「Office付き」と書かれていても、Microsoft Office か互換ソフトかは商品ごとに違うので、商品ページの説明を確認してください。

中古ならではの確認ポイント

バッテリーは消耗品なので、中古品は新品より持ちが短いことがあります。保証期間、外観ランク（傷の程度）、付属品をショップの説明で確かめておくと安心です。周辺機器をつなぐ予定がある方は、端子の種類も見ておきましょう。

おすすめの中古ノートパソコンと周辺機器

マンツウオンラインショップ 第8世代 Core i5 おまかせノートパソコン

特徴：価格は29,800円で、5,000円OFFクーポンも配布されています（いずれも執筆時点）。第8世代 Core i5、メモリ8GB（最大32GBまで増設可能と記載）、SSD 250GB、15.6型、Windows 11 Pro という構成です。Webカメラ、テンキー（数字入力用のキー）、DVDドライブ、無線LAN、Office も付いています。レビューは11,120件、評価4.34で、購入者の多い商品です（執筆時点）。

向いている人：まずは低予算で始めたい方や、文章作成・データ入力が中心の方に向いています。テンキー付きなので、数字の入力が多い経理系の作業にも使いやすい仕様です。

注意点：「おまかせ」は、メーカーや機種をショップが選ぶ形式です。届くまで具体的な機種が分からないため、USB Type-C 端子の有無など細かな仕様は個体によって違う可能性があります。SSD 250GB は、写真や動画を多く扱うと手狭になりやすいので、クラウド保存の併用も考えておきましょう。

向いている人：ビデオ会議をしながら資料を作るなど、同時に進める作業が多くなりそうな方に向いています。CPU の世代が新しくメモリも多いので、長く使える1台を選びたい方の候補になります。

QGeem USB Type-C ハブ 7in1

特徴：価格は2,980円です（執筆時点）。USB Type-C 端子1つに挿すだけで、HDMI（4K対応と記載）、USB 3.0、SDカード・microSDカードの読み取り口を増やせます。PD（USB 経由で給電する規格）に対応し、最大100W の充電をハブ経由でパソコンに送れる仕様です。評価は4.54（2,049件、執筆時点）です。

向いている人：外付けモニターをつないで画面を広く使いたい方や、マウスやキーボードなどの周辺機器を複数つなぎたい方に向いています。デジカメの写真を SD カードから取り込みたい方にも便利です。

注意点：パソコンの USB Type-C 端子が映像出力や PD 給電に対応していないと、HDMI や充電の機能は使えません。特に「おまかせ」の機種は、Type-C 端子自体がない場合もあります。ノートパソコン本体に HDMI 端子があれば、モニター1台ならハブなしでもつなげるので、まず手元の端子を確認してから選びましょう。

まとめ

副業用の1台目は、第8世代以降の Core i5、メモリ8GB以上、SSD を目安にすると、文章作成や事務作業に使いやすい構成になります。費用を抑えたいならおまかせの中古ノートパソコン、同時作業が多く長く使いたいなら dynabook B55/HR が候補です。周辺機器は、パソコンの端子を確認してから買い足すと無駄を減らせます。価格やクーポンは変わることがあるので、購入前に各ショップのページで最新の情報を確認してください。
